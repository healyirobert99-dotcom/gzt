2. 项目目标与系统边界

2.1 项目目标

建立一个面向 A 股与港股的个人投研与交易管理工作台，承接已经过"拉网 / 深穿"研究的标的，将研究结论、交易计划、真实持仓和后续验证放在同一个系统中持续管理。

核心问题：今天有哪些标的发生了值得我处理的变化，我下一步应该按照原来已经确定的计划做什么？

2.2 系统边界（必须做）

  • 承接已完成的"深穿"结论，转化为结构化个股档案
  • 维护研究结论、交易计划、真实持仓的四层分离结构
  • 支持标的从「等证据 → 等价格 → 可交易 → 持仓中 → 暂不参与」的状态机
  • 提供基于"首仓区 / 加仓区 / 强赔率区 / 不追价"的事实化行情对照
  • 维护 append-only 的研究版本、计划版本、交易流水、决策台账
  • 仅在本地运行，数据所有权归用户

2.3 系统边界（明确不做）— 防止范围蔓延

本 MVP 明确拒绝实现以下功能。任何要求新增此清单内能力的请求，应作为新项目立项而非范围变更：
明确不做原因
自动选股 / 自动打分不替代深穿研究
自动生成新投资规则不擅自改写研究逻辑
自动交易 / 算法下单不代替人做执行判断
行情变化自行修改交易计划计划修改必须由人发起并附说明
复杂收益归因 / 因子归因超出 MVP 范围
量化评分 / 量化回测不在工作台职责之内
技术指标系统（MA/MACD/...）用户基于研究结论而非指标
组合优化 / VaR / Monte Carlo超出 MVP 范围
多账户 / 多用户 / 角色权限个人工具，无需
社交 / 新闻门户 / 研报聚合数据源与深穿会话负责
报价"建议买入"信号系统只显示客观事实，价格/区间比对交给人

2.4 与"深穿"会话的关系

环节负责方
标的筛选与拉网深穿会话
单股深穿 / 估值 / 风险评估深穿会话
输出标准化信息卡深穿会话（输出）→ 工作台（导入）

5. 数据模型（SQLite Schema）

5.1 表清单

表名职责是否 append-only
securities标的本身（代码、市场、行业、A/H 关联）可更新元信息；禁止删
research研究结论（版本化）是（永远新增版本，不覆盖旧版）
trade_plans交易计划（版本化）是（同上）
trades真实交易流水是（仅新增，不修改不删除）
decision_ledger决策台账（状态变更 / 计划变更原因）是（纯 append-only）
settings运行期配置（账户总规模等）可更新

5.2 完整 Schema（DDL）

-- 标的表
CREATE TABLE securities (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  name          TEXT NOT NULL,                -- 中文名
  code          TEXT NOT NULL,                -- 原始代码 01357 / 688208
  exchange      TEXT NOT NULL,                -- SH / SZ / HK
  market        TEXT NOT NULL DEFAULT 'A股',  -- A股 / 港股
  industry      TEXT,                         -- 行业标签
  research_pool TEXT,                         -- 所属研究池
  a_h_link      TEXT,                         -- A/H 双向关联代码
  status        TEXT NOT NULL DEFAULT '等证据',
  current_price REAL,                         -- 最近一次行情快照
  current_price_updated_at TEXT,
  created_at    TEXT NOT NULL
);

-- 研究结论（append-only / 版本化）
CREATE TABLE research (
  id                INTEGER PRIMARY KEY AUTOINCREMENT,
  security_id       INTEGER NOT NULL,
  version           INTEGER NOT NULL,
  one_liner         TEXT,                     -- 一句话投资逻辑
  positive_changes  TEXT,                     -- JSON 数组
  core_validations  TEXT,                     -- JSON 数组
  wall_conditions   TEXT,                     -- JSON 数组
  report            TEXT,                     -- 完整研报正文
  research_date     TEXT,                     -- 研究日期
  created_at        TEXT NOT NULL,
  UNIQUE(security_id, version)
);

-- 交易计划（append-only / 版本化）
CREATE TABLE trade_plans (
  id                  INTEGER PRIMARY KEY AUTOINCREMENT,
  security_id         INTEGER NOT NULL,
  version             INTEGER NOT NULL,
  first_zone_low      REAL,                   -- 首仓区下沿
  first_zone_high     REAL,                   -- 首仓区上沿
  add_zone_low        REAL,                   -- 加仓区下沿
  add_zone_high       REAL,                   -- 加仓区上沿
  odds_zone_low       REAL,                   -- 强赔率区下沿
  odds_zone_high      REAL,                   -- 强赔率区上沿
  no_chase_price      REAL,                   -- 不追价
  target_position_pct REAL,                   -- 目标仓位
  next_action         TEXT,                   -- 下一动作
  change_note         TEXT,                   -- 修改说明
  created_at          TEXT NOT NULL,
  UNIQUE(security_id, version)
);

-- 真实交易流水（append-only）
CREATE TABLE trades (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  security_id INTEGER NOT NULL,
  trade_date  TEXT NOT NULL,
  side        TEXT NOT NULL,                 -- 买入 / 卖出
  price       REAL NOT NULL,
  quantity    INTEGER NOT NULL,
  fee         REAL DEFAULT 0,
  note        TEXT,
  created_at  TEXT NOT NULL
);

-- 决策台账（append-only，append-only ledger 思想）
CREATE TABLE decision_ledger (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  security_id INTEGER NOT NULL,
  event_date  TEXT NOT NULL,
  event_type  TEXT NOT NULL,                 -- 标的创建 / 状态变更 / 买入 / 卖出 / ...
  summary     TEXT NOT NULL,                 -- 一句话描述
  reason      TEXT,                          -- 决策理由（不可空）
  created_at  TEXT NOT NULL
);

-- 系统设置
CREATE TABLE settings (
  key   TEXT PRIMARY KEY,
  value TEXT NOT NULL
);

5.4 关键约束

约束实现方式
持仓数量不能为负应用层校验：卖出数量 > 累计可卖数量时返回 400
计划版本号单调递增UNIQUE(security_id, version) + 写入时计算 MAX(version)+1
状态变更必须填写原因POST /status 校验 reason 字段非空
研究/计划版本一旦发布不可改仅 INSERT，不提供 UPDATE / DELETE 接口
外键完整性FOREIGN KEY 已启用（PRAGMA foreign_keys=ON）

6. REST API 规格

6.1 接口总览

方法路径用途
GET/api/securities列出全部标的（包含当前价快照和持仓计算）
POST/api/securities新建标的（含初始研究 + 计划）
GET/api/securities/{id}标的详情（嵌套 security / research / plan / trades / ledger）
POST/api/securities/{id}/status状态变更（必填 reason，自动写入台账）
POST/api/securities/{id}/research新增研究版本（自动 version+1）
PUT/api/securities/{id}/plan新增交易计划版本（自动 version+1）
POST/api/securities/{id}/trades新增交易流水（校验超卖）
GET/api/quotes?symbols=hk01357,sh688208腾讯行情代理
GET/api/settings读取系统设置
PUT/api/settings更新系统设置

13.2 行情解析节选

def fetch_quote(symbol: str) -> dict:
    """腾讯接口返回形如 'v_hk01357="100~..."' 格式"""
    url = f'https://qt.gtimg.cn/q={symbol}'
    raw = urllib.request.urlopen(url, timeout=5).read().decode('gbk')
    # 解析字段：名称 / 当前价 / 涨跌 / 涨跌幅 / ...
    m = re.match(r'v_' + symbol + r'="([^~]+)~([^~]+)~([^~]+)~([^~]+)..."', raw)
    if not m:
        raise ValueError('quote parse failed')
    name, current, _, change_pct = m.groups()
    return {
        'name': name,
        'current': float(current),
        'change_pct': float(change_pct),
        'fetched_at': now_str(),
    }
