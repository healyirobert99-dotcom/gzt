### 本次的真实收获：修了**验证脚本自身**的两个缺陷
- **§6 隔离性不能用 sha256 判**：8765 上用户实例在跑，行情刷新必然改真实库字节。
  上一版把整行都算进业务指纹 → 用户一刷新行情 §6#1 必红（**探针假红**，非产品缺陷）。
  改为「业务数据不变 + 字节变化只限行情两列 + 记录写者 PID + 打印变化明细归因」。
- **`get box` 读数带标签**，`re.findall(r'\d+')` 会把 URL 里的 `8805` 吃进来
  → `width=8805.0` → 按它裁剪**必然裁到空白**。改为逐键正则 + 裁剪后像素差自检。
- 新增 **`cleanup_sandbox_archive.py`**：收尾还原走接口（浏览器点击还原连试 3 轮全失败，
  60 秒重渲染会替换 DOM，会让下一次 E2E 的 §0#2 假红）。
